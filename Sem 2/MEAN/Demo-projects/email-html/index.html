Impact if Not Renewed

Upon expiry, all services using this credential will receive 401 Unauthorized responses. This includes API calls, daemon processes, background jobs, and CI/CD pipelines. Downstream services may experience cascading failures.

Required Remediation Steps
1

Open Azure Active Directory

Navigate to portal.azure.com → Azure AD → App Registrations → All Applications.
2

Select the Application & Open Certificates & Secrets

Find the relevant application and navigate to the Certificates & Secrets blade.
3

Generate New Credential

Add a + New client secret or upload a new certificate. Copy the secret value immediately — it will not be shown again.
4

Update Dependent Systems

Rotate the credential in all consuming services — Key Vault references, config files, CI/CD pipelines, and environment variables — before the expiry date.
5

Validate & Remove Old Credential

Confirm services authenticate successfully, then delete the expiring credential to maintain a clean, auditable inventory.
